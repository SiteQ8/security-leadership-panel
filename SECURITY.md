# Security Policy

## Reporting a Vulnerability
1. **DO NOT** open a public GitHub issue
2. Email: **Site@hotmail.com**
3. Subject: `[SLP Security] Brief description`

### Response: Acknowledgment 48h, status 7d, resolution 30d.

### Scope
**In scope:** XSS, localStorage data exposure, dependency vulnerabilities.
**Out of scope:** NIST/CIS content accuracy, browser-specific limitations.

## Data Privacy
All data stays in browser localStorage. No external servers contacted.

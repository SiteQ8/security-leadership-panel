# Contributing

1. Fork the repository
2. Create feature branch: `git checkout -b feature/your-feature`
3. Edit `docs/index.html` (single-file app — HTML + CSS + JS)
4. Test in browser (no build required)
5. Commit: `git commit -m "feat: description"`
6. Push and open PR

## Standards
- Pure HTML/CSS/JS, no build tools
- Chart.js for visualizations
- Maintain dark mode support for new components
- Follow existing CSS variable naming
- Test responsive layout (desktop + mobile)

## Commit Messages
`feat:`, `fix:`, `docs:`, `refactor:`, `chore:`
